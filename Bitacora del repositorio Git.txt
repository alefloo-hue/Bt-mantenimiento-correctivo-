Bitacora del repositorio Git

Mantenimiento correctivo

Fecha: 28 de septiembre de 2026
Autor: Alejandro Flores Ibarra
Tema: Bitacora del repositorio Git Mantenimiento correctivo


Objetivo

Registrar las fallas encontradas en un repositorio y establecer una solucion para cada problema, con el proposito de mejorar su funcionamiento, seguridad, compatibilidad y rendimiento.

Desarrollo de la actividad

Durante la revision del repositorio se identificaron 13 problemas que podian afectar el funcionamiento del sistema:

1. Roles de usuarios descontrolados: se observaron errores en las autorizaciones.
Solucion: implementar un mejor sistema de autorizacion y control de usuarios.

2. Estilos CSS no validos: se encontraron listas de estilos incorrectas.
Solucion: corregir los estilos y eliminar las reglas sobrantes.

3. Imagenes o archivos no cargados: habia rutas incorrectas de archivos.
Solucion: corregir las rutas y verificar que los archivos existan.

4. Falta de certificado SSL: el sitio no contaba con una conexion completamente segura.
Solucion: instalar y configurar un certificado SSL.

5. Inicio de sesion defectuoso: se detecto informacion mal escrita o incorrecta durante el inicio de sesion.
Solucion: corregir la informacion y validar adecuadamente el proceso de autenticacion.

6. Envio de datos no validos: algunos formularios permitian introducir datos incorrectos.
Solucion: agregar validaciones a los formularios para evitar informacion incorrecta.

7. Incompatibilidad con el navegador: algunas funciones de CSS no eran compatibles con navegadores antiguos.
Solucion: actualizar el CSS y utilizar funciones compatibles con los navegadores necesarios.

8. Enlaces rotos, error 404: se encontraron rutas internas incorrectas.
Solucion: revisar y corregir los enlaces y las rutas internas.

9. Diseno no responsivo: la pagina presentaba problemas al visualizarse en telefonos y computadoras.
Solucion: adaptar el diseno para que responda correctamente a diferentes tamanos de pantalla.

10. Vulnerabilidad de inyecciones SQL: se identifico el riesgo de introducir codigo SQL mediante consultas.
Solucion: separar el codigo SQL de los datos proporcionados por los usuarios y utilizar consultas seguras.

11. Datos duplicados: existian registros repetidos y faltaban restricciones en la base de datos.
Solucion: implementar restricciones que eviten la duplicacion de informacion.

12. Consultas lentas: algunas consultas tardaban demasiado en ejecutarse.
Solucion: optimizar las consultas y mejorar la infraestructura de la base de datos.

13. Error al conectar con la base de datos: se detectaron credenciales incorrectas en las variables del entorno.
Solucion: corregir las variables de conexion y reiniciar el servidor.

Resultados

Despues de analizar las fallas, se establecieron soluciones para cada problema. 

Conclusion

La actividad permitio identificar diferentes errores que pueden aparecer durante el desarrollo y mantenimiento de un proyecto. Tambien se comprendio la importancia de revisar periodicamente el codigo, las rutas, la base de datos, la seguridad y la compatibilidad del sistema. El mantenimiento correctivo ayuda a detectar y solucionar problemas antes de que afecten de manera importante al funcionamiento del proyecto.
